# Samolet: самолётный БАС с бортовым ИИ

Патрульный беспилотный самолёт, который сам находит **лесные пожары** и
**людей, которым нужна помощь на воде**, и передаёт координаты оператору.

Проект команды «Guslitron774» (ДТ «Кванториум», Челябинск) для категории
**«ИКаР-БАС»** конкурса «Инженерные кадры России», сезон 2026/27.

---

## Две задачи — две модели

Принцип: профиль миссии переключается перед вылетом, одновременно работает
одна модель. Это не оптимизация, а необходимость — проверено экспериментально:
«пожарная» модель над водой даёт ложные «огонь» на красных жилетах и «дым» на
ряби; «водная» модель на суше принимает белые прямоугольники и логотипы за лодки.

### Лесные пожары — `runs/mixed_v3_final/weights/best.pt`

YOLO11s, вход 960, классы `smoke` / `fire`. Обучена на D-Fire + 24 своих кадра
с дрона + воздушные кадры AFSE + 129 размеченных веб-фото.

| Проверка | Результат |
|---|---|
| D-Fire test (4306 кадров, не видели) | огонь P 0.715 / R 0.655 / mAP50 0.670; дым P 0.831 / R 0.772 / mAP50 0.797 |
| AFSE holdout (29 кадров с огнём, conf 0.1) | тревога **28/29** |
| То же при conf 0.05 | **29/29**, ложных тревог на пустых кадрах нет |
| Скорость | 8.5 мс/кадр на GPU |

Единственный пропуск — тление без видимого пламени (шум разметки holdout):
модель даёт 0.084–0.087 на всех масштабах, то есть сигнал есть, но ниже порога.

### Люди на воде — `runs/sea_yolo11n_960/weights/best.pt`

YOLO11n, вход 960, классы `swimmer` / `boat` / `jetski` /
`life_saving_appliances` / `buoy`. Обучена на SeaDronesSee (10 477 кадров
с дронов, CC0).

| Класс | P | R | mAP50 |
|---|---|---|---|
| Пловец | 0.840 | 0.803 | 0.759 |
| Лодка | 0.933 | 0.939 | 0.939 |
| Гидроцикл | 0.870 | 0.884 | 0.858 |
| Буй | 0.863 | 0.777 | 0.814 |
| Спасательное средство | 0.835 | 0.437 | 0.448 |

По кадрам: пловец обнаружен на **97.4%** кадров, где он присутствует
(1253 из 1286). Класс `life_saving_appliances` слабый — он занимает 1.6%
боксов в обучающем наборе; на тревогу это не влияет, потому что рядом с
человеком в беде почти всегда есть пловец или лодка.

### Триаж: очередь, а не поток рамок — `training/track_water.py`

Детекция по одному кадру на мелких объектах «мерцает» между пловцом и лодкой.
Поэтому класс объекта определяется по истории трека (взвешенное голосование
уверенностей), а приоритет считается по трём признакам: мала скорость
(не гребёт к безопасности), далеко от плавсредств, долго в воде.

Оператор видит отсортированную очередь с обоснованием, а не сотню рамок.
Проверено на видео из открытых источников: одиночный пловец удерживается
одним треком 433 кадра и выходит в верх очереди.

## Быстрый старт

```
git clone https://github.com/LightRain-K/Sky-rescuer.git
cd Sky-rescuer
python -m venv .venv && .venv\Scripts\activate     # linux: source .venv/bin/activate
pip install -r requirements.txt
python training/check_data.py                      # раскладка data/ — см. DATA.md
```

### Проверить модели

```
python training/eval_model.py <веса огня>     # D-Fire test + AFSE holdout, отчёт в reports/
python training/eval_water.py <веса воды>     # SeaDronesSee val + кросс-домен, отчёт в reports/
```

Правило приёмки огня: fire-recall D-Fire не хуже 0.655, holdout не хуже 28/29.
D-Fire test гонять **только с `batch=1`** — батчевый val виснет на этом сплите.

### Обучить

```
python training/train_mixed_v3.py      # пожарная модель (YOLO11s @960)
python training/train_water.py         # водная модель (YOLO11n @960)
python training/build_mixed_v3.py      # пересобрать объединённый набор огня
python training/build_sea_pex.py       # подмешать размеченные кадры к водному набору
python training/finetune_water.py      # дообучение водной на новых кадрах
```

### Трекинг и триаж

```
python training/track_water.py --video=data/video_probe/lone_swimmer.mp4
python training/track_water.py --seq=13907..14087
```

| Путь | Что это |
|---|---|
| `training/` | обучение, оценка, сборка наборов, трекинг, зонды |
| `data/*.yaml` | конфиги наборов (пути относительные, переносимы) |

либо готовим отдельный маленький квад, либо сознательно целимся в отдельные
номинации, а не в абсолютное первенство.

## Честные границы

Система не ставит диагноз «тонет» и не принимает решений. По одному кадру с
высоты отличить тонущего от плывущего невозможно — и мы этого не обещаем.
Борт обнаруживает, приоритизирует и передаёт координаты; решение за оператором.
