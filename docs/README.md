## Требования к паспорту (из Каталога и Регламента)

- PDF, не более 40 страниц: основная часть 10–20, приложения 5–20.
- Times New Roman 14 пт, интервал 1,5; поля 3 / 1,5 / 2 / 2 см.
- Титульный лист — строго по Приложению №1 Каталога.
- Дополнения после заочного этапа **не оцениваются** — сдавать финальную версию.
- Критериев на 215 баллов; карта соответствия — в конце паспорта (Приложение 8).

## Как пересобрать документы

Нужны `python-docx`, `python-pptx` (для PDF дополнительно Word/PowerPoint
или LibreOffice):

```
pip install python-docx python-pptx pypdf pymupdf
python docs/build_passport_docx.py
python docs/build_presentation_short.py
python docs/build_presentation.py
```

Тексты живут в скриптах сборки — правка в `.docx`/`.pptx` вручную тоже
работает, но при пересборке перезапишется. Если правишь много — правь скрипт.
